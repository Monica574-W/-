# 策方 Ledger · 财务规划 App

根据 Claude Design 原型「财务规划App」实现的静态网页版记账应用，给多人共用设计。

**完全自包含，零外部依赖**：所有代码、字体、图标都打包在这几个文件里，不连接任何第三方服务、不需要 API Key、不需要账号、没有到期或收费的风险。部署上线之后可以完全不用管它，除非你自己想加新功能，否则不需要做任何后续维护。

## 功能

- **首页**：本月结余 / 收入 / 支出、预算使用进度、资产总值、近期收支、记账提醒条、超支提醒横幅
- **记一笔**：收入 / 支出快速记账，分类、备注、日期、支付渠道（微信支付/支付宝/银行卡/现金/其他）、数字键盘；点击已有记录可编辑或删除
- **全部记录**：完整交易列表，支持关键词搜索 + 按类型/分类/月份筛选
- **报表**：按月查看收入支出、支出构成饼图、近 6 个月趋势、消费洞察（环比变化、最大支出分类、超支提醒）、预算 vs 实际
- **预算规划**：按月查看预算使用情况、编辑分类预算上限、储蓄罐（可手动存入）
- **资产清单**：资产现值、购入价、三种折旧方式（按年/按天/按次），可添加/删除资产
- **批量导入账单**：直接导入支付宝/微信支付官方导出的账单 CSV 文件，自动识别金额、收支方向、日期，并猜测消费分类，导入前有核对页面逐条确认（详见下方说明）
- **我的**：
  - 头像 & 壁纸上传、主题皮肤、强调色、白天/夜晚模式
  - 分类管理：新增/删除自定义支出分类
  - 数据备份：导出 JSON 备份文件、导入恢复
  - 安全锁：开启后需要 4 位数字密码才能打开 App（仅本地校验，非加密）
  - 记账提醒：打开 App 时如果当天还没记账会提示（纯本地判断，不是推送通知，见下方说明）

所有数据（记账记录、预算、资产、主题设置等）都保存在**每个人自己手机浏览器的本地存储**里，不同人打开这个网站，看到的是各自独立的账本，互不影响，也不会经过任何服务器。刷新页面或重新打开也不会丢失，但**清除浏览器数据、换手机、换浏览器会导致数据丢失**——请提醒使用的人定期在"我的 → 数据备份"里导出备份文件保存好。

如果开启了"安全锁"，务必记住设置的 4 位密码——这只是本地界面锁，不是加密，忘记密码目前没有找回入口，只能清除浏览器数据重新开始（记得先导入备份）。

## 部署到 GitHub Pages

1. 在 GitHub 上新建一个仓库（例如 `cefang-ledger`）。
2. 把这个文件夹里的所有文件（`index.html`、`style.css`、`app.js`、`manifest.json`、`icons/` 整个文件夹）上传到仓库根目录。
   - 网页版：直接在仓库页面点 **Add file → Upload files**，把文件拖进去，Commit。
   - 或者用 git 命令行：
     ```bash
     git init
     git add .
     git commit -m "init"
     git branch -M main
     git remote add origin https://github.com/你的用户名/cefang-ledger.git
     git push -u origin main
     ```
3. 进入仓库 **Settings → Pages**，Source 选择 **Deploy from a branch**，Branch 选择 `main` / `/(root)`，保存。
4. 等 1-2 分钟，页面会显示一个网址，形如：
   `https://你的用户名.github.io/cefang-ledger/`
5. 把这个网址分享给需要用的人，各自在手机浏览器打开即可。

部署完之后就完事了——没有密钥要配、没有第三方账号要续期、没有服务器要维护。以后如果 GitHub 本身不出问题，这个网站会一直可以访问。

## 添加到手机桌面（像 App 一样打开）

- **iPhone (Safari)**：打开网址 → 点击底部分享按钮 → 「添加到主屏幕」。
- **Android (Chrome)**：打开网址 → 右上角菜单 → 「添加到主屏幕」/「安装应用」。

添加后会以全屏、无浏览器地址栏的方式打开，图标和名称已经配置好（`manifest.json` + `icons/`）。

## 关于"记账提醒"——为什么不是锁屏推送通知

早期版本探讨过接入第三方推送服务（如 OneSignal）做真正的锁屏提醒，但那需要注册第三方账号、保管密钥、配置定时任务——不符合"部署一次、不用维护"的要求，所以最终**没有采用**，改成了一个更简单、完全自包含的方案：

- 打开 App 时，如果当天已经过了 10:00 还没有记过账，首页会出现一条提示条，点一下直接去记一笔。
- 这个判断完全在你手机本地完成，App 关闭之后不会做任何事，也不连接任何服务器。
- 局限很明显：不打开 App 就不会提醒。如果之后确实需要锁屏级别的推送提醒，那必须引入外部推送服务和一定的后续维护，这和"零维护"是矛盾的，需要你自己权衡取舍。

## 如何导出并导入支付宝/微信账单

这个功能可以让你不用一笔一笔手动记账，而是直接把支付宝/微信支付里已有的账单导进来。**全程在手机本地处理，不连接任何 AI 或其他外部服务**，用的是一个内置的 CSV 解析器。

### 导出支付宝账单

1. 支付宝 App → 我的 → 账单 → 右上角"…" → 开具交易流水证明 / 账单下载（不同版本入口名字略有差异，搜"账单导出"也能找到）。
2. 选择时间范围，选择导出为 **CSV** 格式。
3. 支付宝一般会把文件发到你绑定的邮箱，是一个加密压缩包，解压密码会通过支付宝服务通知发给你。
4. 解压后得到 `.csv` 文件，传到手机上（比如用邮件附件直接在手机上打开，或者用"文件"App 之间传输）。

### 导出微信支付账单

1. 微信 App → 我 → 服务 → 钱包 → 账单 → 右上角"…" → 导出账单。
2. 选择时间范围和用途（选"个人对账"就行），确认导出。
3. 微信会生成一个 CSV 文件（可能也是压缩包+解压密码，视微信版本而定），保存到手机。

### 导入到策方 Ledger

1. 打开 App → 我的 → "导入支付宝账单 CSV" 或 "导入微信支付账单 CSV"，选对对应的按钮很重要（两家账单格式不一样）。
2. 选择你刚刚导出的 `.csv` 文件（如果是压缩包，先用手机自带的"文件"App 解压出 csv 再选）。
3. App 会自动识别出每一笔的**金额、收入/支出方向、日期**（这部分来自文件本身，100% 准确），并**尝试猜测消费分类**（这部分是关键词猜的，不一定准）。
4. 会进入一个核对页面，列出识别到的每一笔：可以点掉不想要的（内部转账、失败的交易一般已经自动过滤，但漏网的可以手动取消勾选），也可以点分类下拉框改成正确的分类。
5. 确认无误后点"导入选中的 N 笔"，一次性批量存入账本。

### 目前这个方案的局限

- 只支持**官方导出的 CSV 文件**，不支持截图（截图识别需要 OCR，免费的浏览器端 OCR 库准确率有限，还是账单文件更可靠，所以没做）。
- 分类是关键词猜的（比如看到"肯德基"猜餐饮、"滴滴"猜交通），不认识的商家会给一个默认分类，需要在核对页面手动改。
- 银行卡账单格式因银行而异没有统一标准，目前没有支持。

## 文件说明

```
index.html    页面结构、字体（系统字体，无外部字体）、PWA 配置
style.css     基础样式、动画、深色底色、字体变量
app.js        全部应用逻辑（状态管理、渲染、CSV 解析、localStorage 存储）——唯一的代码文件，无需构建
manifest.json 添加到主屏幕所需的 PWA 配置
icons/        应用图标（192/512/苹果触控图标）
```

没有任何 `<script src="https://...">` 之类的外部脚本引用，没有 Google Fonts，没有第三方 SDK——所有东西都在这几个文件里。

## 本地预览

无需安装任何东西，双击 `index.html` 直接用浏览器打开即可预览：

```bash
cd 项目文件夹
python3 -m http.server 8000
# 然后浏览器打开 http://localhost:8000
```
